# 🚦 Semáforo da Comunicação em Interfaces Web

Este projeto apresenta um guia prático de boas e más práticas de comunicação visual e textual em ambientes digitais, organizado em **15 cards** divididos em três categorias baseadas no semáforo (Verde, Amarelo e Vermelho).

## ♿ 6 Práticas de Acessibilidade Aplicadas
1. **Identificação Multissensorial:** As categorias e avisos não utilizam apenas cores; dependem obrigatoriamente de textos explicativos, emojis e símbolos visuais (`✅`, `⚠️`, `🚫`).
2. **Alto Contraste Visual:** Seleção de cores de texto e fundo testadas para garantir alta legibilidade segundo as diretrizes WCAG.
3. **Navegação Completa por Teclado:** Foco visível (`outline`) em todos os elementos interativos e link de atalho `"Pular para o conteúdo principal"`.
4. **Hierarquia Semântica Limpa:** Organização estruturada em tags HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) e títulos ordenados (H1, H2, H3).
5. **Design Responsivo:** Layout adaptável para smartphones e computadores usando `CSS Grid`, `Flexbox` e `@media queries`.
6. **Legibilidade Aprimorada:** Alinhamento de texto à esquerda (evitando textos justificados) e fonte limpa sem serifa.

## 🚀 Como publicar no GitHub Pages
1. Crie um repositório público no GitHub chamado `semaforo-da-comunicacao`.
2. Adicione os arquivos `index.html`, `style.css` e `README.md`.
3. Acesse **Settings** > **Pages** no repositório.
4. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
5. O site estará disponível em instantes!
